# The `docs/` index

Every document under `docs/`, with a full annotation each — what it covers,
and why it says what it says. **Read this index rather than guessing from
filenames**: several of these files are named for a subsystem but organized
around a lesson, and the annotation is what tells them apart.

This index used to live inline in `CLAUDE.md`'s `## Structure` section. It was
moved here on 2026-09-03, verbatim, for the same reason the milestone narrative
moved to [`CHANGELOG.md`](CHANGELOG.md): `CLAUDE.md` is read at the start of
*every* session, whether or not any of this is relevant, while an index next to
the documents it indexes is read when it is needed — and is far likelier to stay
current, since it is edited in the same commit as the doc it describes.
`CLAUDE.md` keeps a short pointer list and defers here.

The **postmortems** are the largest group. Each one also opens with its own
title, an italic abstract, and its spine in a blockquote, so the annotation
below is only there to help you choose which to open.

Sequel to repairing-the-repairs' "a claim in a comment is not a check", moved one step: a claim that is wrong on arrival can be caught by a careful reader; a claim that is RIGHT on arrival passes every review it will ever get, and is then falsified by an unrelated change in another file. Lessons: a goal phrased as a FEEL (POSIX-ish) doesn't constrain the architecture, the load-bearing requirement (isolation) does, and the aesthetic loses silently; enforcing isolation DELETES the kernel-centric syscall model; fork is the primitive a microkernel can't cheaply honor (spawn is what per-task isolation wants - Fuchsia agrees); portability is a userland libc PERSONALITY not a kernel property (Fuchsia/MINIX3/APE run C via a compat libc over a non-POSIX kernel); the Phase-0 fid deferral came back as the key (a POSIX fd IS a 9P fid - one feature, two payoffs); and the most important architectural clarifications sometimes have NO failing test (only attention catches a goal-vs-reality drift). Output isn't code - it's the reconciliation: architecture.md's philosophy subsection + ROADMAP.md's portability plan + comparison.md + this account
