
I'd like to make my own operating system, made in Rust (and assume some assembler).

It'll be for ARM64, and I'll do the tests on Parallels on Mac Silicon.

I'd like it to have a micro-kernel, and the system calls I think probably should follow the POSIX standard.

And it should be preemptive multitasking like any modern OS does

Haven't decided what kind of file system it should support yet. Needs a little research for that. Perhaps only support some simpler FS at first.

Going to need a shell of some kind to start programs, but also a kernel that loads device drivers and such.

Essentially I'd like it to be similar to Linux, but draw ideas from Minix, Plan-9 and other *x operating systems.

Eventually perhaps create an library of programs like editor, compiler, or whatnot.
